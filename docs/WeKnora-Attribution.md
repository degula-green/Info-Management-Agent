# WeKnora Attribution

This prototype reuses selected frontend source and assets from Tencent WeKnora:

- `src/components/GlobalCommandPalette/ResultGroup.vue`
- `src/components/GlobalCommandPalette/ResultItem.vue`
- `src/components/css/suggested-questions.less` (used by the adapted `creatChat` layout)
- TencentSans font, theme variables, and WeKnora logo assets

Source repository: <https://github.com/Tencent/WeKnora.git>

The upstream repository is licensed under the MIT License. See the upstream `LICENSE` file for the complete copyright and permission notice. The Info Agent adaptations are local prototype code and do not connect to WeKnora services. API/store-heavy WeKnora views keep the upstream layout and TDesign interaction grammar while using local mock state.
