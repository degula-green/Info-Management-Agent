# WeKnora 前端功能与适配提示词

## WeKnora 页面功能梳理

- 登录/注册：账号登录、邀请注册、错误提示、主题与语言入口。
- 工作台侧栏：知识库列表、会话列表、全局命令面板、个人菜单、设置入口。
- 全局命令面板：关键词搜索知识片段、消息、知识库、会话和问答；分组展示；支持快捷键、结果预览和检索设置。
- 知识库列表：搜索、卡片/列表展示、知识库详情、文档上传、文档预览/下载/编辑、标签和批量操作。
- 新建对话：快速模式、推荐问题、范围选择、文件输入和回答引用。
- 对话详情：消息流、引用来源、附件预览抽屉、下载和编辑。
- 设置/个人中心：个人资料、密码、空间、模型、检索、存储和连接器配置。

## 可直接发送给其他 AI 的提示词

```text
请以 Tencent WeKnora GitHub 仓库（https://github.com/Tencent/WeKnora.git）的前端源码为唯一视觉和组件参考，检查其真实 Vue 3 + TypeScript + TDesign Vue Next 页面，不要自行发明新的 UI 组件、颜色体系或页面结构。Info Agent 当前只需要一个无接口的本地交互原型，所有数据用 mock，禁止 fetch、axios 和后端调用。

请直接复用 WeKnora 的：
1. 登录/注册双栏布局、TDesign 表单控件和主题变量；
2. 左侧工作台菜单、顶部全局搜索入口、个人菜单和设置页 setting-row 布局；
3. GlobalCommandPalette 的命令面板、ResultGroup、ResultItem、标签、抽屉和文件预览交互；
4. 知识库卡片、搜索框、详情层级、消息列表、文件列表和响应式规则。

Info Agent 的业务约束：
1. 注册填写用户名、邮箱、密码、确认密码，不发送验证码；注册成功后使用邮箱和密码登录。飞书、企业微信、个人微信只能在登录后的个人中心绑定，不能用于登录。
2. 顶层知识库固定只有飞书、企业微信、个人微信，不能创建或删除。未绑定来源必须锁定；绑定后进入“来源 -> 群聊知识库 -> 消息/文件”的层级。
3. 用户可在来源内选择群聊、历史采集起点、是否持续采集和轮询状态；暂停后可恢复并重新选择起点。
4. 全局搜索支持关键词、向量和混合模式，搜索消息、文件、群聊和问答记录。点击群聊进入完整消息上下文；点击消息、文件或问答打开 WeKnora 风格详情抽屉，提供编辑、保存和下载的本地交互。
5. AI 问答只做 WeKnora 快速模式：勾选一个或多个群聊作为回答范围，输入问题后显示本地示例回答和来源范围。
6. 个人中心上半部分沿用 WeKnora 的个人资料布局，但头像和昵称由用户自己设置；下半部分改为飞书、企业微信、个人微信连接器，绑定/解绑只更新本地状态。页面明确“仅本人可查看”。

实现要求：
- 优先复制 WeKnora 的真实组件和 CSS/主题文件；只有业务差异才新增薄适配组件。
- 保持 TDesign Vue Next 的按钮、输入框、标签、抽屉、空状态、错误状态和键盘焦点行为。
- 桌面端保持 WeKnora 的侧栏 + 顶部搜索 + 内容区；移动端折叠侧栏并堆叠内容，不允许文字溢出。
- 交互必须可演示：登录、注册校验、打开命令面板、执行搜索、打开群聊、打开文件抽屉、编辑保存、下载提示、绑定连接器、暂停/恢复采集、选择问答范围。
- 交付前运行生产构建并检查桌面/移动端截图；输出所复用的 WeKnora 文件清单和未接入后端的边界。
```
